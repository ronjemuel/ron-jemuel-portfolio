# Ron Jemuel — portfolio

A five-page student developer portfolio built with HTML, CSS, and JavaScript.

**Live website:** https://ron-jemuel-portfolio.vercel.app/


## Files

| File | Page or purpose |
| --- | --- |
| `index.html` | Home |
| `about.html` | About |
| `skills.html` | Skills |
| `projects.html` | Projects and category filters |
| `contact.html` | Contact details |
| `style.css` | Shared styling and responsive layouts |
| `script.js` | Navigation, filters, scrolling, and reveals |
| `assets/` | Local images, icons, fonts, and their upstream licenses |

## Hosting

This is a static website. For Vercel, select **Other** as the framework, enable the Build Command override and leave it empty, and use `.` as the output directory.

The current website was deployed directly from its files. GitHub automatic deployments must be connected separately in Vercel before repository changes update the live site.

The profile photograph is the supplied original PNG, framed with CSS. Project previews use actual captures or clearly identified brand covers. Contact links open the visitor's phone or email application.

Font and icon licenses are included beside their respective assets.
